# 👁️ ایجنت ریلز اینستاگرام (Insta Reels Agent)

ایجنت پایتونی با رابط گرافیکی که مرورگر را باز می‌کند، با یوزرنیم/پسورد شما وارد
اینستاگرام می‌شود، به‌صورت خودکار ریلز را اسکرول می‌کند (پیش‌فرض ۵۰۰ ریل) و هر ریل را
در پوشه‌ای روی سیستم شما دانلود می‌کند — به‌همراه فایل لینک‌ها و گزارش کامل.

## ✨ امکانات

- 🖥️ **رابط گرافیکی مدرن** (دارک‌تم با CustomTkinter): آمار زنده‌ی بازدید/دانلود/خطا،
  نوار پیشرفت، تخمین زمان پایان، لاگ رویدادها و لیست ریل‌های اخیر با کپی لینک.
- 🌐 **باز کردن خودکار مرورگر** با Playwright (Chromium داخلی یا Google Chrome سیستم).
- 🔐 **ورود با یوزرنیم/پسورد** + پشتیبانی از تایید دو مرحله‌ای و چالش امنیتی
  (به‌صورت دستی در همان پنجره حل می‌شود).
- 💾 **ذخیره‌ی نشست**: دفعات بعد بدون رمز وارد می‌شود. رمز هرگز روی دیسک ذخیره نمی‌شود؛
  فقط کوکی نشست با دسترسی محدود (`~/.insta_reels_agent/`) نگه داشته می‌شود.
- 👁️ **حالت فقط-تماشا (سخت‌گیرانه)**: در کد هیچ کلیکی روی لایک/کامنت/فالو/سیو/اشتراک وجود
  ندارد؛ تنها کنش‌ها: «Next»، `ArrowDown` و اسکرول موس.
- 📺 **اسکرول هوشمند ریلز**: برداشت لینک کانونیکال هر ریل با ریتم انسانی
  (مکث تصادفی + استراحت دوره‌ای) در سه سطح امن/متعادل/سریع.
- ⬇️ **دانلود هم‌زمان** با دو ورکر yt-dlp به‌محض دیده‌شدن هر ریل، توی پوشه‌ی دلخواه شما.
- 📋 **خروجی لینک‌ها**: `links.txt` (هر خط یک لینک) و `manifest.jsonl` (گزارش کامل
  دیده‌شده/دانلودشده/ناموفق).
- ♻️ **ادامه‌ی اجرای قبلی**: اگر وسط کار قطع شود، دفعه‌ی بعد ریل‌های دیده‌شده دوباره
  شمرده نمی‌شوند و دانلودهای ناتمام/ناموفق خودکار اول صف تلاش مجدد قرار می‌گیرند.

## 🚀 نصب و اجرا

```bash
pip install -r requirements.txt
python -m playwright install chromium   # فقط بار اول
python main.py
```

> لینوکس: اگر خطای tkinter گرفتید → `sudo apt install python3-tk`
> اختیاری: برای دانلود پایدارتر، `ffmpeg` نصب باشد.

## 🧭 روش استفاده

1. یوزرنیم و پسورد اینستاگرام را وارد کنید (رمز فقط در حافظه می‌ماند).
2. تعداد ریل‌ها (پیش‌فرض ۵۰۰)، ریتم اسکرول و پوشه‌ی دانلود را تنظیم کنید.
3. **«شروع ایجنت»** را بزنید → پنجره‌ی مرورگر باز می‌شود.
4. اگر تایید دو مرحله‌ای یا چالش امنیتی آمد، در همان پنجره حلش کنید؛ ایجنت صبر می‌کند.
5. ایجنت شروع به اسکرول می‌کند و هر ریل بلافاصله در صف دانلود قرار می‌گیرد.
6. هر وقت خواستید **«توقف»** را بزنید؛ لینک‌های برداشت‌شده در `links.txt` می‌ماند.

## 📂 ساختار خروجی

```
<پوشه‌ی دانلود>/
├── <uploader> - <shortcode>.mp4    ← ویدیوها
├── links.txt                       ← همه‌ی لینک‌های برداشت‌شده
└── manifest.jsonl                  ← گزارش دقیق هر رویداد
```

## ⚠️ نکات مهم (بخوان!)

- **قوانین اینستاگرام**: اتوماسیون و دانلود انبوه با شرایط استفاده‌ی اینستاگرام ناسازگار است
  و ممکن است اکانت را (موقتاً) محدود کند. با اکانت مهم‌تان ریسک نکنید و ریتم **امن** را
  با تعداد پایین‌تر شروع کنید.
- **حق‌نشر**: محتوای دانلودشده فقط برای **استفاده‌ی شخصی** است؛ بازنشر بدون اجازه‌ی سازنده ممنوع.
- **زمان واقعی**: ۵۰۰ ریل با ریتم امن چیزی حدود ۱.۵ تا ۳ ساعت طول می‌کشد — تخمین،
  داخل برنامه نمایش داده می‌شود.
- **توقف موقت اینستاگرام**: اگر فید گیر کرد، ایجنت خودش صفحه را تازه می‌کند؛ اگر محدودیت
  خوردید، چند ساعت صبر کرده و ادامه دهید (ادامه‌ی خودکار پشتیبانی می‌شود).
